# Caso Práctico — AI-900T00 SENATI
## Tema: Uso de chatbots en E-commerce

---

## Empresa: InnovVentas

**Rubro:** Comercialización de productos tecnológicos  
**Problema central:** Baja interacción en sitio web → impacto negativo en ventas y retención de clientes

---

## Problemas Identificados

| Problema | Impacto |
|----------|---------|
| Los usuarios abandonan el proceso de compra | Alta tasa de carritos abandonados |
| Falta de respuestas rápidas a consultas | Pérdidas anuales significativas |
| Dudas sin resolver: especificaciones técnicas, métodos de pago, disponibilidad | Baja competitividad en mercado digital |

---

## Requerimientos del Chatbot

El chatbot debe:
- Responder **preguntas frecuentes** (FAQs)
- **Asistir en el proceso de compra** de forma automática y eficiente
- Ofrecer **soporte técnico básico**
- **Integrarse** al sitio web existente
- Permitir la **recopilación de métricas** para medir impacto en ventas y reducción de carritos abandonados

---

## Condiciones para el Desarrollo

1. Contar con las herramientas necesarias: plataforma para desarrollar el chatbot y acceso al sitio web donde será integrado.
2. Realizar un estudio de las interacciones de los usuarios para identificar las preguntas frecuentes.

---

## Entregables Requeridos

- [ ] Descripción de necesidades del cliente y problemas identificados en el flujo de E-commerce
- [ ] Diseño del Chatbot: esquema de interacciones, flujo de conversación, preguntas frecuentes, diagramas/mapas conversacionales
- [ ] Explicación de plataformas y frameworks con justificación de elección
- [ ] Plan de Implementación: pasos para integrar el chatbot al sitio web
- [ ] Esquemas y/o diagramas alineados a la propuesta de solución

---

## Preguntas Guía

1. ¿Cuáles son las preguntas frecuentes más comunes que enfrentan los clientes al usar el sitio web de InnovVentas?
2. ¿Qué herramientas o plataformas son más adecuadas para desarrollar e integrar el chatbot al sitio web?
3. ¿Cómo se puede evaluar la efectividad del chatbot en términos de satisfacción del cliente y aumento de ventas?
4. ¿Qué desafíos técnicos podrían surgir durante la implementación del chatbot y cómo podrían resolverse?
5. ¿Qué métricas deben monitorearse para asegurar el éxito del chatbot y cómo se pueden optimizar sus funcionalidades?
